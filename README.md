## What I built with BlinkHost

BlinkHost grew from delivering websites for family, friends and clients. The browser workspace, CLI, inbound MCP and Idam work with the same project state, resources and releases. Idam connects native platform actions with authorized client repositories, databases and services. A Django control plane, custom Rust edge, WebAssembly backend execution and managed libSQL data support the application and delivery workflows.

Building it has meant owning the product decisions, developer experience, runtime, data flows and deployment tooling together. [Read the full case study →](https://onyedika.blinkhost.website/_server_islands/api/read/work/blinkhost)
